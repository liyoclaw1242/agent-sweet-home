agent-sweet-home · localhost HTTP API

HTTP API Reference

App 啟動時在 127.0.0.1:<random-port> 開 axum server， 供外部 CLI / agent / workflow engine 呼叫。 Port 和 Bearer token 寫在 <app_data_dir>/server.json。

Auth
  • 除 GET /health 外，所有端點需帶 Authorization: Bearer <token>
  • Token 在 server.json 的 token 欄位；每次 App 啟動重新生成
  • Port 在 server.json 的 port 欄位；OS 隨機分配
  • Token 缺失或錯誤 → 401 Unauthorized
curl http://127.0.0.1:$(cat ~/Library/Application\ Support/agent-sweet-home/server.json | jq .port)/health

System

GET /health no auth Liveness check
Response
200 OK  →  "ok"

POST /one-shot bearer Start a new claude -p run
Request body — RunArgs (JSON)
FieldTypeDescription
repoIdintegerrequiredDB repo id
repoNamestringrequiredRepo short name
cwdstringrequiredWorking directory for the spawn
promptstringrequiredPrompt passed to claude -p
modelstringoptionalModel override, e.g. claude-opus-4-7
outputFormatstringoptionalstream-json (default) | json | text
skipPermissionsbooleanoptional--dangerously-skip-permissions
systemPromptstringoptionalFull system prompt override
appendSystemPromptstringoptionalAppended to default system prompt
allowedToolsstring[]optionalTool whitelist, e.g. ["Bash", "Read", "Edit"]
disallowedToolsstring[]optionalTool blacklist
maxBudgetUsdnumberoptionalHard spend cap in USD
addDirstring[]optionalExtra directories added to context (--add-dir)
namestringoptionalDisplay name / --name flag; workflow engine sets {role}-{mode}-issue{N}
mcpConfigstring[]optionalMCP config file paths
resumestringoptionalSession UUID to resume
continueLastbooleanoptional--continue flag
extraArgsstring[]optionalRaw extra flags
Response
201 Created  →  RunInfo (same shape as GET /one-shot list item)
200 OK 400 Bad Request — cwd missing or spawn failed 503 Service Unavailable — app_handle not ready
GET /one-shot/{id} bearer Get single run metadata
200 OK → RunInfo 404 Not Found
DELETE /one-shot/{id} bearer Kill (if running) or delete (if finished)
204 No Content — deleted 202 Accepted — kill signal sent (was running) 404 Not Found
Deleting a finished run cascades to its log lines.
GET /one-shot/{id}/log bearer Stream log lines (incremental polling)
Query params
ParamTypeDefaultDescription
sinceinteger-1Return lines with seq > since. Pass last received seq for incremental polling.
limitinteger1000Max lines to return
Response 200 — LogLine[]
[
  {
    "runId": "my-repo-1715000000-ab12cd34",
    "seq": 0,
    "ts": 1715000001,
    "stream": "stdout",
    "text": "{\"type\":\"assistant\",\"message\":{...}}"
  },
  {
    "runId": "my-repo-1715000000-ab12cd34",
    "seq": 1,
    "ts": 1715000002,
    "stream": "stderr",
    "text": "Loaded MCP server..."

]
For outputFormat: stream-json, stdout lines are newline-delimited JSON (Claude stream events). Poll with since=<last_seq> to receive incremental updates.
