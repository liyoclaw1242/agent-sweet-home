06 · Future considerations · post-v1

Three moves borrowed from "Agent Twin"

A parallel prototype the user generated separately took a different overall direction (light cream + chat REPL + bubble radius — conflicts with harbormaster brief), but three of its moves transplant cleanly into ASH. Queued for v0.2 evaluation after the cockpit baseline ships. Not in v1.

FC-1

Repo card at the top of the sidebar

Replaces the top-bar dropdown. Frees ~180px of top-bar space for Cmd+K and packs more information per glance: branch + ahead/behind + last commit + today's spend.

FC-2

Slash-command pills for One-Shot quick-launch

Modal stays as the canonical "full custom run." Pills are the power-user shortcut layer — saved preset prompts launch with one click, no modal. Worth it once a user has 3+ prompts they repeat weekly.

/review-prreview current PR diff /fix-lintrun linter + autofix /update-readmesync README to code /explain-diffexplain HEAD~1..HEAD +new preset
requires preset library persistence + settings UI to manage presets
FC-3

Cost meter expands to a stacked spend bar

Hover or click the top-bar cost meter to expand it into a horizontal stacked bar broken down by source — each running terminal and run gets a colored segment proportional to its share. Turns the meter from "how much" into "where is my money going right now."
